Adapted from React Bits Folder Float TS/CSS for the studio skill folders.

The official perspective folder flap, paper rise, spring cloud layout, stagger, Matter.js zero-gravity drift, collision boundaries, and draggable material cards are retained. The preview cards use equal square rounded frames and optional image thumbnails. Folder activation is separate from hover/focus cloud opening, and controlled `open`, visual `selected`, and chapter `enabled` states are supported. Hidden, offscreen, closed, or disabled folders stop the physics loop. The application supplies its own local assets and warm palette.
