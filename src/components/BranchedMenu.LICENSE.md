Adapted from React Bits Branched Menu TS/CSS for the studio skills chapter.

Retains the rounded SVG tree, 400ms accent-line drawing, 300ms grid fold and active trunk marker. Uses existing Lucide icons, a single open branch, default selection of its first skill, and a bounded image/detail region in the site's warm palette. Inactive branches are inert and removed from keyboard navigation; reduced-motion/static mode disables animation. No new package dependencies.
